CINEMAX - MOVIE INFORMATION PORTAL
==================================

Open index.html in a modern browser.

Folder structure
----------------
Cinemax_Movie_Portal/
  index.html
  movies.html
  movie-details.html
  favorites.html
  reviews.html
  contact.html
  css/
    style.css
  js/
    movies.js
    app.js
    home.js
    movies-page.js
    details.js
    favorites.js
    reviews.js
    contact.js
  images/

Features
--------
- Home banner, featured/popular movies and genres
- 15 movie records stored as JavaScript objects
- Dynamic movie cards using DOM
- Search, genre/language/year/rating filters
- Sorting by name, rating and release year
- Dynamic movie details
- Favorites/watchlist using LocalStorage
- Reviews and ratings using LocalStorage
- Contact/feedback form validation
- Dark/light mode using LocalStorage
- Responsive layout for desktop, tablet and mobile
- Trailer buttons
